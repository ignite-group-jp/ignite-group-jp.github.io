# IGNITE Partners Corporate Website

IGNITE Partnersの公式コーポレートサイトです。

## Structure

- `index.html` — サイト本体
- `_headers` — 配信時のセキュリティヘッダー
- `assets/brand/` — ブランド画像

## Local preview

静的ファイルとして配信できます。ローカルでは任意のHTTPサーバーで確認してください。

## Hosting

GitHub Pagesで `main` ブランチのルートから配信し、カスタムドメイン `ignitepartners.jp` を使用します。
